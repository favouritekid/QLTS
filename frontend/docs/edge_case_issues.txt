  🔴 HIGH RISK - IMMEDIATE ACTION NEEDED                                        
                                                                                
  #9: Incomplete Consultation Data (P0)                                         
                                                                                
  Problem: No validation that consultation has minimum required data before     
  allowing Admission creation.                                                  
                                                                                
  Current State:                                                                
  - Consultation can be created with only scheduled_at and notes                
  - No check for key fields: consultation_status_id, officer_id                 
  - Lead can proceed to Admission with incomplete consultation history          
                                                                                
  Risk: Orphaned leads in pipeline with no clear status/ownership.              
                                                                                
  Recommendation:                                                               
  # In admission_service.create_profile():                                      
  async def _validate_consultation_completeness(lead: Lead):                    
      latest_consultation = lead.consultations[-1] if lead.consultations else   
  None                                                                          
      if not latest_consultation:                                               
          raise BusinessRuleViolation("Lead must have at least one              
  consultation")                                                                
      if not latest_consultation.consultation_status_id:                        
          raise BusinessRuleViolation("Latest consultation must have a status")
